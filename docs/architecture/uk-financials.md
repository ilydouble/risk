# 英国事件前历史财务补充

## 观察时点与范围

- 输入为 `uk-adverse-events-2020-2025-v1/events.csv`，保留全部事件和原字段。
- 用户确认提前 12 个月预测；观察日取事件参考月份向前移 12 个月后的月末。
- 事件源只有月份精度，因此这里不是精确到某天的违约预测样本。
- 按 Companies House 公司编号关联，保留前导零；待注册局核验的编号不猜测匹配。
- 观察日前回看 36 个月的电子财报提交归档，扫描 2016-01 至 2024-11 共 107 个月。

## 官方来源与时间约束

来源为 [Companies House 历史月度电子财报](https://download.companieshouse.gov.uk/historicmonthlyaccountsdata.html)。
归档按提交月份分组，成员文件名含公司编号和会计期末日期。
通过 HTTP Range 读取 ZIP 中央目录及目标文件，固定 ETag，核验解压大小、CRC 和 SHA-256。
不下载每个归档中的所有企业；原始财报和索引均保存在独立缓存中。

月归档不提供逐份财报的精确公开日期。本版采用“归档月份的次月末”为保守可用日假设，
仅选择该日期及会计期末均不晚于观察日的文件，`exact_filing_date` 留空。
该日期是月粒度建模假设，不能描述为已核验的历史公开日期。
严格逐日回测仍需 filing history / 文件元数据确认真实公开日期。

每个企业、观察月份按会计期末、归档月份降序选取最多三份候选，
最新候选没有支持的金额或解析失败时尝试较早候选。
同会计期末、同归档月份的多份文件按文件名字典序确定顺序；不声称能判断月内修订先后。
缓存针对冻结来源版本；刷新官方归档时使用新的缓存和输出目录。

## 事实与缺失

提取 17 类指标：资产、固定资产、流动资产、流动/非流动负债、净流动资产、
资产减流动负债、现金、存货、应收、净资产、权益、营业收入、净利润、营业利润、税前利润及员工数。

- 只接收支持的官方 UK GAAP / FRC / IFRS 概念；不通过标签文字猜测金额。
- 资产负债指标要求期末时点上下文，收入利润和员工数要求期间上下文。
- 不取财报中的比较期间；不将分部或带任意维度的事实当作企业总额。
- `Creditors` 只接受已知的流动/非流动期限维度。
- 同指标存在金额、币种或期间冲突时留空；不强行选择其中一个。
- 使用 Decimal 处理符号、缩放和格式转换；保留原始币种，不换汇、不用零补空。
- 原始金额、概念、上下文、会计期间、单位及转换参数随事实表交付。
- 每个指标有独立 `_missing` 字段；真实的零仍为观测值。

流动/非流动负债字段也接收相应期限的 `Creditors` 余额；简化报表可能另列准备金、应计负债等，
因此这些字段不是已完全标准化的负债总额。跨企业比较或计算比率时需要结合原始概念及报表口径。

微型/小型企业常只提交简化资产负债表，利润和营业收入缺失是正常情况。
未找到电子财报不等于企业从未报送：可能是纸质文件、早于窗口、未支持格式或其他来源限制。
默认无维度上下文仍可能包含合并口径，本版未完成所有公司/集团会计口径的逐份判定。
文档内注册号存在时必须与文件名一致；未提供注册号时保留未核验标志，不伪造验证通过。

## 交付与恢复

入口 `scripts/prepare_uk_financials.py`，依赖独立于后端：

```sh
uv run --no-project --with-requirements scripts/requirements-uk-financials.txt \
  python scripts/prepare_uk_financials.py \
  --events datasets/archive/uk-research-20261017/uk-adverse-events-2020-2025-v1/events.csv \
  --output datasets/archive/uk-research-20261017/uk-financials-2020-2025-h12-v1 \
  --cache datasets/sources/uk-financials --horizon 12 --lookback 36
```

相同命令可以续跑：索引、候选选择、原始文件和按解析器源码哈希区分的解析结果均缓存。
下载失败下次重试；解析规则更改会重新解析原始文件。
`report.json` 的 `transfer` 只统计当前进程的网络读取，续跑不会把先前缓存下载量重复累计。

| 文件 | 用途 |
| --- | --- |
| `event-financials.csv` | 全量事件左关联财务，含观察时点和缺失原因 |
| `financial-reports.csv` | 去重财报、官方 URL、成员位置、CRC、SHA、身份校验状态 |
| `financial-facts.jsonl.gz` | 每项金额的原始概念和上下文证据 |
| `selection.jsonl.gz` | 每个企业/观察月份的候选文件 |
| `archive-manifests.json` | 官方 ZIP 固定版本与索引摘要 |
| `retrieval-errors.json` | 无支持金额、解析/下载失败的具体文件 |
| `report.json` | 覆盖数、指标完整度、源码/输入摘要及来源限制 |
| `validation.json` | 独立全量关联、时间、金额和原始证据校验 |

原始财报缓存位于 `datasets/sources/uk-financials/documents/`，不会改动历史交付。
结构化包和原始来源证据分别打包，说明中列出范围及摘要。
本交付是事件企业财务补充表；尚未加入正常对照样本、历史企业状态或生成新的模型训练包。
关联表中的事件类型、事件参考月份、后续程序及原始事件证据属于标签/审计信息，不能直接作为预测特征。
后续训练需显式选择观察日前财务事实、缺失标志、财报年龄等允许字段，不能对整张关联表自动编码。

## 验证

`scripts/tests/test_uk_financials.py` 覆盖日期边界、上下文、冲突、真实零、数值转换、
ZIP Range/CRC、缺失企业保留和未来财报拒绝。
独立校验器对照原始事件、事实和缓存证据，检查行数、外键、金额、SHA/CRC和观察日期约束。
