## 结论与限制

- 三臂为累积消融，相同输入/嵌入/损失权重/预算：社区先验提升 PR-AUC 与校准
  （ComRisk → RiskGNN），真实证据双分支再提升 PR-AUC、ROC-AUC 与 Brier
  （RiskGNN → RiskGNN+）。
- ECE 最优的是 RiskGNN 而非 RiskGNN+，差距在一个标准差内，不能宣称 RiskGNN+ 全面占优。
- 正样本率 3.59%，绝对 AUC 与 SMEsD（57.6%）不可直接比较；PR-AUC 基线约 0.30，
  故 0.355 的绝对提升有限。
- 本表是**复现补充实验**，`run_smesd_experiments.py` 的 “RiskGNN+” 是分类器 + 熵替代，
  两者结果不可互相引用。
- 制品可重放：`seed_*/predictions.npz` 保存全部概率、不确定性、冲突与分支概率，
  `source_snapshot/` 与 `manifest.json` 的 SHA-256 逐文件一致。
