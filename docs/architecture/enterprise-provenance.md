# 企业属性展示与原始记录追溯

## 页面与范围

上传企业详情分别展示企业顶层字段、attributes和features，不把已转换字段称为原始值。
0、空字符串与null分别展示；没有名称时仍沿用企业标识作为展示名称，不编造企业名称。
字段含义、单位及标签定义来自当前来源，不从字段名推断贷款违约或其他业务含义。

CSV转换来源新增“原始记录与来源追溯”：文件、原始记录序号、CSV物理起止行、
源字段及原值、目标及转换后值、忽略项、缺失处理、标签映射、去重行及冻结规则。
折叠区显示来源案例、任务ID、执行器、规则版本、文件/产物摘要和导入时间。
可以打开源案例继续查看当前方案，但页面追溯始终使用导入时规则。

## 来源核验与兼容

不改数据库结构，不改写旧转换产物及摘要，已有CSV导入无需重新上传或导入。
通过EnterpriseImport.manifest.taskId找到已导入任务，再读取冻结ConversionPlan与源CSV。
Dataset、任务、源案例三者均绑定当前账号，任务还必须关联当前数据集。
检查原文件SHA-256、源案例摘要、数据集冻结计划/摘要、导入产物摘要和规则指纹。
仅支持已知执行器版本；通过同一固定转换逻辑重算匹配企业原始行，并核对已保存企业值。
来源缺失、版本不支持、标识歧义或核验失败均返回unavailable说明，仍正常展示企业属性。
不以当前准备记录的新映射解释历史导入，也不根据企业编号猜测其他来源。
标准训练包导入仍展示完整属性；未提供原始CSV行级来源时明确显示不可追溯。

## 行号、去重与显示限制

原始记录序号不计表头及空行；CSV物理行号计入表头、空行及引号内换行。
完全相同原始行仅保留一条，追溯显示主记录和被去重行；忽略字段仍参与原始整行去重。
重复行位置最多展示100条，同时保留总数及截断标记。
单个原值及转换后文本最多展示4096字符，界面明确提示；完整内容仍在源文件/企业记录中。
追溯为只读操作，在线程中解析受限CSV，不重新训练、推理、导入或更改用户数据。

## 契约与验证

企业详情响应新增可选ResponseEnterpriseProvenance和字段对照项，OpenAPI导出后生成前端类型。
业务服务不依赖HTTP DTO。转换与追溯共用convert_record/convert_value，保持原执行器输出一致。
测试覆盖前导零、0与null、忽略字段、重复原始行、引号内换行、物理空行及截断标记。
隔离PostgreSQL验证旧任务追溯、后续映射修改仍使用冻结规则、跨账号拒绝、源文件异常
时隐藏未经核验的追溯且继续展示已导入属性。
