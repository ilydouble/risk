# 英国研究数据 v3：金额、异常与国家

本轮在 v2 上生成独立版本，不重采样、不改变企业全集、标签、事件或图结构。用户接受“当前登记与历史观察一致”的粗略研究假设；记录为假设，来源时间和未核实标记仍保留。本轮不把不良事件放入输入图。

## 本次全量结果

- 重解析 208,853 份原件，209,192 条观察逐条关联，原件摘要/大小/CRC32 全部一致。
- 有金额观察从 206,033 条（98.49%）增至 208,705 条（99.77%）；2,673 条恢复金额、1 条因极端金额隔离转为缺失。
- 回补 25,414 个空字段；其中从 Original 维度接受 25,407 个报告事实，观察字段数与报告事实数不是同一分母。
- 隔离 1,264 个员工数字段、2 个极端金额字段；保留其原值和证据。负员工值、注册号误入、scale 和大数复核理由可能重叠。
- 国家规范值 93,291 条：GB 93,289、AX 1、AF 1；4,664 条聚合值和 5 条模板占位转为缺失。外国披露代码保留原文供复核，不据此保证披露真实。
- 20,341 项流动余额关系复核警告、3,064 项负资产余额复核警告，均保留原值；科目范围差异、取整与源标注等均可能影响等式，警告不等于确认数据错误。
- 全部 229,907 家研究企业、58 家母公司、普通关系、超边、成员关联、标签、事件和配对文件保持不变。

## 金额回补

全量读取已有选定财报原件，每份核对原有 SHA256、大小和 CRC32；沿用原报告、报告期末和假定可用日，不按完整程度换选财报。

受信 XBRL 分类中的 `OriginalRevisedDataDimension=Original` 是原始版本元数据，允许与原有科目上下文结合。`Revised`、分部、合并维度、未知或非受信维度仍不允许替代企业事实。上下文中的其他企业编号不能混入本企业。

原始版本与无该维度的事实如发生不同数值、单位或报告期间，继续作为冲突留空，不选择更完整或更有利的值。应付/负债类 `Creditors` 仍须由期限维度明确映射流动或非流动，不能把未知期限猜成一年内。

## 字段质量政策

版本为 `uk-financial-quality-v1`，以字段为单位处理，全部企业和观察保留。

| 条件 | 动作 |
|---|---|
| 非有限数 | 隔离字段 |
| 平均员工数为负、等于数字企业注册号 | 隔离字段，不取绝对值、不替换为零 |
| 平均员工数超过 100,000 或使用非零 scale | 待复核隔离，不直接断言源数据必错，不自动除以 1,000 |
| GBP/EUR/USD 金额绝对值达到 1000 亿 | 待复核隔离；不是普适财务上限，后续可用原证据解除 |
| 固定/流动资产、存货、应收款为负 | 保留并警告；不因符号直接重写金额 |
| 流动资产－流动负债与净流动资产不一致 | 同币种时检查；残差超过 max(3, 最大绝对余额×1%) 仅保留警告 |
| 负净资产、负利润、零值、非负平均员工小数 | 正常保留，不把亏损或平均数当成脏值 |

这些阈值用于当前研究数据的保守复核，不是企业规模或会计标准的客观边界。新版本提供 `financial-source-facts.jsonl.gz` 和逐字段质量证据；原财报和 v2 仍保留。清洗结果中隔离字段为空、missing=True，相关原值只能从审计/源证据读取。

`financial_missing` 仍表示没有可接受金额；仅有员工数不算金额。清洗后重新计算币种与全部字段 missing 标志。质量和来源审计列不是默认模型特征。

## 国家规范化

- 注册国家字段统一为国家代码，英格兰、威尔士、苏格兰、北爱尔兰和 England and Wales 均归为 `GB`，同时单独保留注册辖区。
- `AllCountries`、未知集合、模板占位符转为缺失，保留原值、状态和来源；不从企业编号推断国家，也不拿当前状态暗填历史事实。
- 明确描述“incorporated in England/Scotland…”可按显式文本规范化；不能识别的内容仍为空。
- 对本次出现的外国名称按显式映射规范化，映射表不是完整世界国家词典。保留原披露及其来源，不据规范代码推定注册信息真实性。
- 当前登记的 `CountryOfOrigin` 与注册地址国家保留原列，另加规范列；当前地点不自动成为历史地点。

## 文件与版本契约

原企业/图/事件/标签/配对文件逐一核对相同摘要；历史观察中允许变化的旧列仅为 17 个财务指标及其 missing、金额缺失/币种、国家及其 missing。其余旧列不变。

`financial-facts.jsonl.gz` 保存清洗事实；`financial-source-facts.jsonl.gz` 保存质量处理前所选事实；冲突候选保留冲突字段清单，完整原件仍可追溯。`financial-value-changes.csv` 逐观察列旧值、新值、原因。`financial-quality-issues.jsonl.gz` 区分隔离与保留警告。

`historical-basic-profiles.jsonl.gz` 保存规范国家及每个原事实，`country-normalization-summary.csv` 汇总转换，`features.csv` 保存国家代码、辖区、原值与规范化状态。旧版说明/清单归档至 `provenance/v2/`，根目录清单不继续宣称已更改的财务文件与 v2 相同。

三个脚本依次负责：`repair_uk_research_data.py` 全量重解析生成新目录，`validate_uk_research_repairs.py` 独立核对，`finalize_uk_research_repairs.py` 更新清单、再次验证并打包。

复现示例（仓库根目录，安装 `scripts/requirements-uk-financials.txt`）：

```sh
python scripts/repair_uk_research_data.py --base outputs/uk-research-graph-20261017-v2 --output outputs/uk-research-graph-20261017-v3 --workers 4
python scripts/finalize_uk_research_repairs.py --base outputs/uk-research-graph-20261017-v2 --output outputs/uk-research-graph-20261017-v3
```

只接受新版本目录；损坏原件或身份/时间冲突会终止生成。财务缓存签名包含质量策略文件，基本信息缓存签名包含国家映射文件，避免修改规则后误用旧缓存。交付包复用已有财务源数据包，不重复加入解压后的约 20 GB 原件。
