# 模型版本与智能助手

## 职责

- 工作台负责训练、独立测试和发布；模型版本表负责查看、下载和删除发布记录。
- 助手通过当前账号绑定的工具发现模型、查找企业、执行预测，不提供训练、发布或删除工具。
- 工具调用业务 Service；业务后端通过内部 HTTP 调用模型服务，仍不加载模型权重。
- 工具输出沿用持久化的 ToolCallItem，前端展示调用过程；模型结果由业务服务存入企业预测表。

## 工具链路

1. `enterprise_risk_catalog(dataset_id?, limit=10, model_id?)`：按发布时间倒序列出版本。
   返回模型 ID、名称、发布时间、算法、数据集、测试指标、目标定义和示例企业 ID。
   `limit` 限制在 1–50；`model_id` 可精确查询不在最近列表中的旧版本。
2. `enterprise_risk_companies(model_id, keyword="", page=1)`：按 ID 或名称查询该模型所属数据集。
   每页 20 家；名称多义时先让用户选择，不能猜测企业 ID。
3. `enterprise_risk_predict(model_id, company_id)`：执行单企业推理并保存结果。
   RiskGNN+ 请求特征敏感性解释；普通 RiskGNN 保留预测，明确没有解释。

用户明确要求“最新”时可使用目录首项，否则多个候选版本应先确认。
示例 ID 列表是模型发布时最多 100 家的预览，不是完整模型图索引。
企业检索覆盖所属数据集，预测服务最终校验企业是否在模型绑定图内。
模型图外企业返回现有错误，不切换模型、不伪造结果。
输出必须保留测试质量、标签含义及未校准提示；特征敏感性不是 SHAP 或因果贡献。

## 前端入口

- 模型版本表提供查看、下载和删除，并可携版本 ID 前往助手。
- `/chat?riskModel=<版本ID>` 预填查询该版本、选择企业的草稿。
- `/chat?riskModels=recent` 预填浏览最近版本的草稿。
- 企业详情原有的 `riskDataset/riskModel/riskCompany` 入口继续可用。
- 跳转仅填入草稿；用户发送后才执行工具，不自动消费模型请求。
- 聊天页不依赖工作台页面组件，工具只访问已认证账号的资源。

## 删除语义

`POST /api/v1/modeling/delete-model` 接收 `{modelId, confirm: true}`。
页面弹窗明确说明范围后提交；接口校验当前账号及协议代际。
同一事务删除发布版本及其关联的企业预测，保留来源实验、数据集、对象存储模型包。
保留助手历史消息；历史模型 ID 不会自动指向其他版本。
从原实验重新发布得到新的版本 ID，不恢复已删除预测。

删除与发布使用来源实验锁协调；删除与预测落库使用版本锁协调。
已开始的预测可先完成，随后删除其记录；删除完成后新预测返回资源不存在。
删除不是物理清理模型包，也不能撤销已签发且尚未过期的下载 URL。

## 验证边界

测试覆盖工具注册、两类模型预测、目录过滤、企业范围、跨账号访问和删除后拒绝预测。
数据库验证使用临时 schema；不删除用户已有发布记录。
真实 LLM 是否正确选择工具仍取决于上游模型；工具权限和参数校验由服务端保证。
