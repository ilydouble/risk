# 独立数据准备与工作台交付

> 当前主流程已升级为[脚本驱动的数据准备](script-data-preparation.md)。
> 本文记录的映射/固定转换/手动打包保留在历史兼容入口 `/data-prep/legacy`。


## 职责

数据准备工具位于 `/data-prep`，分为“智能体分析与转换”和“训练包生成与交付”。
原始文件体检、智能体报告、映射编辑、受控转换、试运行和交付都由准备工具负责。
工作台 `/modeling` 接收标准ZIP，负责服务端数据校验、版本管理、训练、评估和模型发布。
工作台提供准备工具入口与只读来源卡片，不再重复编辑映射或分析原始文件。
当前仍在同一仓库部署，通过模块和契约划分职责，无需新增服务。

```text
原始材料 → 智能体分析 → 确认语义与规则 → 受控转换 / 模型适配
                                                ↓
                                选择适配器预设和版本，生成标准ZIP
                                                ↓
                              下载后手动上传 / 在准备工具直接上传
                                                ↓
                                    工作台独立校验 → 实验与评估
```

## 三种产物

- 原文件与映射交付包：源文件、报告与映射说明，供继续适配，不是训练包。
- 案例转换产物：核验后的企业属性与已有关系，导入后用于概览与检索；
  `browseOnly=true`，不能冒充训练数据。
- 标准训练包：由适配器声明的必需文件和 `risk_dataset_contract.json` 组成，
  独立于准备记录，可下载、传递或直接上传工作台。

智能体可分析统计、保存受控规则并执行试运行。当前不运行智能体任意脚本，
也不把任意CSV自动构图或随机划分成训练集。缺失的业务语义、关系证据和独立划分
仍需按模型适配器要求补齐；浏览器打包不能替代这一步。

## 标准包生成

选择已适配的数据根目录、预设和版本。浏览器保留源文件字节和目录结构，
依据预设写入根契约，检查必需文件、重复路径、目录越界、成员数量和资源大小。
源目录已有根契约时只在输出包中替换；嵌套契约拒绝。源文件不被修改。
ZIP使用存储模式，避免极端压缩率被服务端拒绝；源文件合计最多511 MiB，
为契约和ZIP头预留空间，输出仍受512 MiB限制。更大输入可用现有独立打包CLI。

预设来自 `models/riskgnn/dataset_adapters/*/delivery.json`；执行
在 `frontend/` 运行 `npm run delivery:generate` 更新前端快照，`npm run delivery:check` 检查漂移。
前端镜像保留生成快照，无需复制模型代码。浏览器使用预设默认参数，
与独立CLI生成同一契约结构；实验参数仍在工作台按配置契约调整。

打包成功只说明 packaging-only 检查完成，不证明标签、引用、独立划分有效。
上传后Worker始终重新执行模型适配器的全量校验，通过后才能训练。

## 上传与来源

准备工具和工作台复用同一个上传函数：申请上传凭证、上传对象、完成上传。
不维护第二套数据集、模型或实验列表。准备侧上传成功返回数据集ID和工作台链接，
状态显示“等待工作台校验”，不能把上传成功称为训练可用。

独立标准包不要求创建准备案例。若由当前已确认案例派生，可显式勾选来源关联；
后端按账号重新检查确认状态并封存源摘要、映射和时间，不再要求先移交案例。
已有 `inWorkbench` 标记与旧移交接口保留兼容，新的准备流程不依赖该标记。
已上传数据集的来源快照不随后续映射编辑而变化。

带有旧 `preparation` 参数的工作台链接仍可读来源；修改方案跳转回数据准备，
也可显式取消本次上传的案例关联后上传独立标准包。

## 验证

前端交付测试覆盖权威预设漂移、契约与源字节、缺文件、越界路径、重复和嵌套契约。
后端准备记录回归覆盖未移交但已确认案例的上传、未确认/跨账号拒绝和来源快照冻结。
