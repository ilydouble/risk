# 已导入企业局部关系图谱

## 数据边界

入口为企业检索→已上传数据集→企业详情。复用现有企业详情响应中的related.edge与
related.hyperedge，不读取演示图，也不根据统计特征补造关系。节点编号作为邻居标签，
打开邻居详情后读取该企业真实属性。图谱范围固定为当前账号、数据集和企业快照。

接口每类最多返回20条关系，页面显示已加载数/总数，不能解释为完整全库图。
图谱最多100个节点，每个群组最多展开12家企业，始终保留当前企业；同时显示完整
群组规模、未展开成员位置数及受画布上限隐藏的记录数。原始记录不受展示截断影响。

## 表达与交互

普通关系保留source→target方向和关系类型；群组显示金色群组节点，成员连接为无向
虚线，不展开成企业两两相连的团，也不解释为持股、风险传播或预测结果。
企业节点使用蓝色，不根据缺失的风险评分填造红黄绿等级。

复用共享G6画布，支持缩放、拖动和重置。按关系类型筛选；点击企业提供同数据集
详情入口，点击群组或连线显示类型、完整成员数、证据权重和源文件SHA/数组位置。
缺少逐条来源时明确说明。选择框提供与画布点击同等的节点和关系来源访问方式。

未导入关系的案例显示空态及补充关系数据入口，不加载演示网络。事件仍在原始记录区，
不转换成未定义的企业关系。既有独立演示图谱入口不受本次企业详情接入影响。

## 验证

前端语义测试覆盖方向、节点ID命名空间、群组不造两两边、大群组上限与中心企业
保留、快照及关系类型筛选。浏览器使用英国真实样例群组临时验收画布和逐条来源，
并核验既有CSV数据集空态；不为视觉验收写入用户数据集。临时页面验收后移除。
