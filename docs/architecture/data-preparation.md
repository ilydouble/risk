# 数据准备试用版

## 当前能力

侧栏「数据准备」独立于模型工作台。用户上传 UTF-8 CSV（最多 2 MiB、50000 行、100 列），
后端完整扫描文件，返回行数、重复行数、逐列缺失和不同值数量、数值占比、常见值及前五行预览。
企业编号始终按文本保留；分析不改变文件，也不将未知标签映射为正常标签。

用户可再调用现有内网大模型获取字段用途建议。提示仅包含字段统计与常见值，
模型返回字段名、用途、理由及待确认问题；后端检查建议只引用已有字段和允许的用途。
建议不是已确认配置，不触发数据导入或训练。未配置/无法连接模型时，体检仍可使用。

当前分析结果只在浏览器页面内保留，刷新后清空。此版本用于验证真实数据体检流程；
尚未接入数据库只读连接、Excel、字段确认、持久配置、跨表关联、数据集构建和新企业预测。

## 后续接入点

确认字段语义和实体关联后，应生成版本化的原始快照、映射配置及数据集产物，
再交给现有 DatasetAdapter / RiskGNN+ 准备链路。当前工作台只接受带契约的 ZIP；
现有 RiskGNN+ 模型预测仍绑定训练图，不能将本页建议直接当作新企业预测能力。
