# 数据准备试用版

## 当前能力

侧栏「数据准备」独立于模型工作台。用户上传 UTF-8 CSV（最多 2 MiB、50000 行、100 列），
后端完整扫描文件，返回行数、含缺失记录数、重复行数，以及逐列缺失、不同值、
类型线索、常见值频次、数值四分位与疑似离群值、日期解析比例和前五行预览。
同时标出混合格式、前后空格、全缺失/常量列、前导零和疑似企业标识重复；
基于列名给出实体/关联键候选与疑似标签的取值分布；二分类少数类低于 10% 时提示不均衡。
不根据 0/1 推断标签语义，单表无法验证外键关系。
企业编号始终按文本保留；分析不改变文件，也不将未知标签映射为正常标签。
预览中的长值仅展示前 80 字符及省略号，统计仍基于完整值。

用户可再调用所选大模型获取字段用途建议。提示包含字段统计、质量线索和键候选，
不发送前五行原始记录。模型返回字段名、用途、理由、质量风险、待确认问题与下一步核查；
后端检查建议只引用已有字段和允许的用途。
建议不是已确认配置，不触发数据导入或训练。未配置/无法连接模型时，体检仍可使用。
字段建议的输出上限与模型问答共用设置页选定值，默认 4096 tokens。

智能体模型配置位于独立的「智能体模型设置」页面，可使用后端默认模型，或输入兼容
Chat Completions 的接口地址、模型名和可选密钥，并调用后端测试连接。当前自定义配置
用于数据准备的字段建议和模型问答；地址与模型名可保存在当前浏览器，密钥仅在登录页面内存中。
在设置页和数据准备页间切换会保留当前数据体检结果；刷新后清空。后端不返回默认密钥，
也不持久化自定义密钥。自定义地址限定为 HTTP(S) Chat Completions 路径，
拒绝环回和链路本地地址；字段统计、常见值及模型问答内容发送到用户选择的模型服务。
页面提供 OpenLux `api.openlux.ai` / `Qwen3.6-35B-A3B` 预填，具体模型 ID 需以账号控制台
为准，并可在页面修改。自定义兼容接口不会发送内网 Qwen 专用的 thinking 参数。

当前分析结果只在浏览器页面内保留，刷新后清空。此版本用于验证真实数据体检流程；
尚未接入数据库只读连接、Excel、字段确认、持久配置、跨表关联、数据集构建和新企业预测。

## 后续接入点

确认字段语义和实体关联后，应生成版本化的原始快照、映射配置及数据集产物，
再交给现有 DatasetAdapter / RiskGNN+ 准备链路。当前工作台只接受带契约的 ZIP；
现有 RiskGNN+ 模型预测仍绑定训练图，不能将本页建议直接当作新企业预测能力。
