# 统一数据资产目录

智能助手通过 `asset_catalog` 发现共享企业演示、新加坡统计快照和当前账号工作台数据集，
通过 `asset_read` 读取目录中的完整资产 ID。工作台深入查询使用 `workbench_catalog` 和 `workbench_ask`。

- 共享演示和个人数据分别统计，不合并为个人上传量。
- 新加坡全量聚合数与可检索固定样本数分开说明，演示标签不视为在线预测。
- 工作台数据集按当前账号隔离，记录数为已导入标准记录数，不等于原始文件行数。
- 数据目录不清点模型或训练实验；模型状态须通过工作台查询。
- 数据准备案例、分析报告和浏览器临时快照不再提供，见[移除说明](data-preparation-removal.md)。
