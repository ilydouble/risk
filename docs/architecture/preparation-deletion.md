# 数据准备案例删除

## 入口与范围

在数据准备页打开已保存案例后，选择“删除案例及关联数据”。弹窗先从服务端读取
实际删除数量，包含原始上传文件、案例分析报告、映射/规则、转换任务及产物，
以及通过本案例转换导入的企业、关系、群组、数据集和预测记录。

删除限定当前账号、当前案例版本，不清理共享演示、仓库样例、其他案例或助手历史对话。
未保存的待上传文件存在时按钮不可用；删除成功清除页面案例、文件选择、报告及映射状态。
用户必须勾选已核对范围，再按“确认永久删除”；取消只关闭弹窗，不发删除请求。

## HTTP 契约与并发

POST /api/v1/data-prep/delete-preview返回counts、datasetIds、blockedReason和revision。
POST /api/v1/data-prep/delete要求preparationId、confirm=true和预览revision。
revision覆盖案例更新时间、转换任务、关联数据集、记录数量和依赖。删除前重新读取，
范围变化返回DATA_PREP_DELETE_STALE，需重新预览并确认，不沿用旧勾选状态。

删除与导入均先锁案例，再锁关联数据集；补充文件创建版本也锁原案例，防止确认范围
核验后又新增版本。删除在同一事务内按外键依赖顺序执行，失败不提交部分结果。

存在后续案例版本、训练/实验依赖或独立ZIP上传数据包时，返回DATA_PREP_DELETE_BLOCKED。
后续版本应从末端依次清理；训练数据和对象存储产物不通过此案例按钮绕过依赖删除。
来源不存在或跨账号读取/删除统一返回404。助手无删除工具，必须通过页面确认。

## 验证

隔离PostgreSQL回归覆盖跨账号拒绝、预览无写入、范围变化阻断、训练依赖阻断、
后续版本保护、完整company/edge/hyperedge与报告/规则/任务删除，其他案例保留。
请求契约拒绝未确认或未携带预览版本的删除。
