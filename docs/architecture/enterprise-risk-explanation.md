# 企业状态预测与解释

## 入口和范围

企业详情从同数据集已发布模型中选择版本，点击“预测并解释”；也可点击“让智能助手解读”，跳入聊天并预填企业、数据集和模型ID，用户发送后执行。助手通过 `enterprise_risk_catalog` 查询当前账号发布版本，通过 `enterprise_risk_companies` 定位所属数据集企业，再用 `enterprise_risk_predict` 实际推理。版本管理、删除与普通 RiskGNN 的无解释预测见[模型版本与助手](assistant-models.md)。工具不发布模型、不启动训练、不导入数据。

只支持模型绑定图中的企业。数据准备案例仅导入浏览数据时没有训练模型，不产生预测。英国标签是登记不良状态分类，分数未经概率校准，不能作为未来违约概率。

## 计算方法

`training-median-intervention-v1` 在冻结模型和图上逐项替换当前企业的一个输入为训练目标企业中位数。中位数在模型变换空间计算，再按冻结预处理参数逆变换回原单位展示；原值是模型使用的输入，可能已填补缺失。参考群体不包括验证、测试或上下文节点。

每项 `delta = 原分数 - 替换后的分数`。正值表示当前输入相对参考值提高分数，负值表示降低；界面换算为百分点。每次只替换一项，权重、嵌入和关系固定，成功或失败后都恢复原输入。不修改模型产物。

这是局部敏感性分析，不是SHAP或因果归因，各项不可相加。相关特征的逐项替换可能形成少见组合。普通关系、超边及事件只作为事实和来源证据展示，未计算单条关系贡献。

## 契约和保存

`POST /modeling/predict-model` 增加默认false的 `explain`。普通预测仍支持最多32家；解释一次仅接受1家，旧模型不支持时返回稳定错误。模型服务在既有PREDICT操作返回特征、参考值、替换分数和差值。

后端验证账号、发布版本、返回企业ID及数据摘要；补充模型ID/名称/摘要、标签定义、UTC评估时间、独立测试指标和质量警告。解释存入既有企业预测JSON；重新计算解释可更新该记录，普通预测不会覆盖已有解释。旧记录没有解释时仍可显示并补算，无数据库迁移。

测试ROC-AUC不高于0.5或测试全部判正例时，页面与助手保留明确质量警告。解释只能说明模型如何响应输入，不能使低质量模型变可靠。

## 证据与账号隔离

助手目录联查账号模型、实验和数据集，默认返回最近10个、最多50个发布版本。用户明确要求“最新”时可按倒序首项选择；否则多个模型时先让用户选择。预测工具的owner由服务端绑定，不允许模型指定。

助手读取同数据集企业属性与来源；每类关系最多展示5条，每条最多20个群组成员，保留总数并声明截断。企业详情链接携带模型版本，用户可回到原始属性、文件追溯和图谱核对。属性或来源中的文本仅作为数据，不作为指令。
