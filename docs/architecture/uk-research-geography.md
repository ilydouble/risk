# 行政地区与行业×地区超边

本轮只扩展独立研究数据集，不修改工作台、训练器或标签。
在 v3 基础上生成 v4，保留全部 229,907 家研究企业、58 家母公司及原关系。

## 来源与行政含义

- [ONSPD August 2026 官方数据](https://www.arcgis.com/home/item.html?id=189f78ab06fd4df4a35fe806d022c563)：
  英国当前及已停用邮编对应的当前行政区代码；仅精确查询研究所需邮编。
- [ONS May 2026 英国行政区关联表](https://www.arcgis.com/home/item.html?id=79e0950fa93446b996d0f3f95537ab6d)：
  提供地方行政当局、大区、组成国的官方代码和名称。
- 企业邮编及行业仍来自 2026-09-30 Companies House 登记快照。
- 两位/五位 SIC 继续使用已有官方 SIC 2007 分类，排除 74990、99999 占位用途代码。

原始查询按批缓存，保存官方服务元数据、版本、请求邮编、响应、ObjectId 和摘要。
提取前后检查服务编辑版本一致；长参数使用 POST，响应超限则分页。
目录匹配精确到规范化完整邮编，不使用城镇名称猜测行政区，也不模糊匹配。
未知、缺失、歧义均保留为未映射；不将行政区缺失值变成共享群组。

地方行政当局涵盖英国，英格兰大区仅适用于英格兰。
苏格兰、威尔士和北爱尔兰的伪大区代码不建群组，也不强行套用英格兰层级。
原有邮区、邮政分区、邮政城镇及共享地址超边继续保留其邮政含义。
侧表 `ons_country_code` 是 ONS 组成国地理代码，不能当作此前规范化的 ISO 国家代码。

## 图结构

新增六类：地方行政当局、英格兰大区、两位 SIC×地方行政当局、五位 SIC×地方行政当局、
两位 SIC×英格兰大区、五位 SIC×英格兰大区。

每个群组至少两家不同企业；多行业企业可以属于多个行业及交叉群组。
交叉群组成员严格等于两个组成群组成员集合的交集，不是并集。
`group-components.csv` 指明交叉组的行业、行政地区两个组成群组；不是所有权边。
完整 GraphML 表示为群组节点＋企业成员关联，不展开成企业两两连接。
新增成员证据指向登记原行、行业原字段和目录原响应，保留全部原超边及证据前缀。

## 时点与当前假设

用户明确允许“当前登记近似历史观察”。静态图使用当前登记地址和当前登记行业，
新增映射使用固定 2026 行政区划；这是一项研究假设，不能宣称已经核实历史地址或历史边界。
因此图的 `historical_prediction_eligible` 与历史核实标志仍为 False，另在清单记录用户假设。
登记地址也不证明企业实际经营地，集中注册代理地址可能形成较大的群组。

`observation-geography.csv` 提供与 209,192 条观察一一对应的地区侧表：

1. 优先使用已提取、在观察时点可用财报中的邮编。
2. 目录的启用月份须不晚于观察月，停用月份须不早于观察月；仅有月份精度。
3. 无可用历史邮编时，回退到当前登记邮编，明确标记 `current_registry_assumption`。
4. 没有可靠目录命中时保留未映射；不删除样本，不填入未知共享地区。
5. 所有映射仍是固定 2026 区划投影，不能当作当年真实行政边界。

邮编生命周期检查只能排除明显不适用的映射，不能验证企业当时的地址；邮编也可能被复用。
历史财报邮编可能对应报表期末、签署或申报时点，精确地址变更时间仍未知。
侧表不混入静态图成员，不伪装成按月重建的历史图。
后续取得历史地址和区划版本后，应按观察日期生成版本化成员关联，再取消相应粗略假设。

## 与财务扩展衔接

v4 的 v3 财务、标签、事件、配对原样保留；不良事件仍是企业观察标签。
`uk-financial-history-20261017-v1` 独立扩展继续使用，包含上期、变化及趋势字段。
其 `features.csv` 按 `sample_id` 关联地区侧表，按 `company_id` 关联图中企业。
两包均保留，v4 不重新装入多期扩展及大体积原财报。

## 本版结果

保留 229,965 个企业节点和 155 条普通关系；合计 50,226 个超边、1,530,711 条成员关联。

| 新增类型 | 超边数 | 成员关联数 |
| --- | ---: | ---: |
| 地方行政当局 | 349 | 118,477 |
| 英格兰大区 | 9 | 108,916 |
| 两位行业×地方行政当局 | 11,324 | 126,348 |
| 五位行业×地方行政当局 | 20,525 | 120,076 |
| 两位行业×英格兰大区 | 738 | 120,816 |
| 五位行业×英格兰大区 | 4,052 | 132,702 |

新增共 36,997 个超边、727,335 条成员关联；静态地方行政区群组覆盖 118,477 家企业。
官方 361 个地方行政当局中，本研究有至少两家企业的 349 个才建组，不因目录存在就造空组。
查询 78,282 个规范邮编，78,047 个精确命中、235 个未命中、0 个歧义。

209,192 条观察全部保留：75,128 条使用历史财报邮编、71,297 条使用当前登记假设，
62,767 条未映射；共 146,425 条有地方行政区，134,694 条有英格兰大区。
上述“历史财报邮编映射”仍不是历史地址、边界核实，不能把覆盖数当作严格历史可用率。

## 复现与验证

从 `backend/` 使用项目 Python 环境，附加依赖 lxml==6.1.3、httpx==0.28.1：

```sh
python ../scripts/fetch_uk_postcode_geography.py
python ../scripts/extend_uk_geography.py
python ../scripts/validate_uk_geography.py
python ../scripts/finalize_uk_geography.py
```

默认目标为 `outputs/uk-research-graph-20261017-v4`，已存在时构建拒绝覆盖。
未来复现优先使用交付包冻结的源码和目录缓存，默认网络服务可能更新；版本不一致不能混用。
验证涵盖旧文件逐字节保留、全部端点、旧组保留、交叉集合、逐成员来源、缺失和伪代码、
观察全量保留、完整 GraphML 节点及边数；交付清单覆盖所有文件并核验 ZIP CRC 和 SHA256。
