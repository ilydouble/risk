# 预测解释的计算边界

## 问题与修复

2026-10-18，助手调用`enterprise_risk_predict`时收到MODEL_SERVICE_UNAVAILABLE。
内部模型服务日志确认：`Runtime.predict`运行解释子进程超过60秒，被监督器取消。
该轮问答本身完成，失败发生在风险预测工具；更早一轮的上游AuthenticationError是另一条请求。

模型已完成训练，所选企业也在绑定图中。解释使用训练目标的逐列中位数作为参考，
为298个字段分别修改当前观察的输入、执行完整快照前向，再恢复输入。
失败企业有220个字段原值已经等于参考值，这些干预实际上没有改变任何输入。

修复：原值与参考值完全相同时直接使用基线概率，仅对真正变化的字段执行前向。
所有298个字段仍返回，未变化字段的delta严格为0；没有删减解释字段或引入近似归因。
异常时仍通过finally恢复整行输入，原模型权重和准备数据不变。
这依赖既有评估期确定性预测契约，不适用于推理期随机采样的模型。

服务60秒推理限制、后端70秒HTTP等待和助手180秒轮次限制保持不变。
密集输入或更大图仍可能耗时较长，此优化不构成所有规模的延迟保证。
