# UK研究数据的模型适配

默认UK预设升级为版本2，数据根目录不变：`datasets/uk_research/`。
可上传模型包是其中的 `model-input.zip`，原始数据包仍用于审计和复核。

## 输入与语义

- 以观察ID为节点身份，真实企业编号和观察月份保留在属性中。
- 训练2019–2020、验证2022、测试2024，隔离12个月预测窗口。
- 跨集合企业不重叠；病例/对照整对保留或排除，排除原因随包交付。
- 数值白名单、有符号log1p、训练集填补/标准化；类别训练词表独热编码。
- 十五类超边保持独立；图关联严格同集合、同观察月，不制造事件输入。
- 新图原155条并表边保留在原始数据，但严格训练投影中没有普通关系边。

## 接口与兼容

`uk-dataset-v1 / 2` 为新协议，`uk-companies` 绑定该版本。
`uk-companies-legacy` 绑定版本1，继续解释旧七维静态分类，不静默变更旧实验。
新格式 `uk-research-v2` 已加入模型声明，前端预设从delivery声明重新生成。
未改HTTP接口或DTO。

RiskGNN+工作台准备和前向按声明类型数量建立超边通道，保持旧三通道权重兼容。
空普通图禁用普通关系分支，不补边；有符号变换在解释输出时逆变换回原单位。
旧RiskGNN工作台node_edge仍是无超图路径，不将其冒充完整RiskGNN图研究对照。

转换与打包命令、数量及限制见
[UK适配器说明](../../models/riskgnn/dataset_adapters/uk_dataset_v1/README.md)。
