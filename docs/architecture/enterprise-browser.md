# 上传数据贯通总览与企业检索

## 用户流程

1. 在工作台上传带已注册适配器契约的数据包。
2. 校验成功后，后台自动将标准企业产物导入企业表；离开工作台不影响继续处理。
3. 在总览或企业检索顶部选择当前数据集，两页共用该选择。
4. 查看该数据集的企业、人物、普通关系、超边、事件和已有标签统计。
5. 企业检索按名称或ID查询已导入全量企业，可选择同数据集模型叠加已有预测。
6. 点击企业详情查看原始属性、同快照关系与事件、各模型已有预测。

工作台“企业数据”提供“查看总览”“进入企业检索”直接入口。
切换选择保存在当前账号的本地浏览器设置中，URL参数可显式覆盖。
选择器每页加载100个数据集，可点击“加载更多数据集”。
既有新加坡样本保留为独立可选快照，不与上传企业合并或自动改写。
上传数据不套用新加坡专属字段、图表或标签语义。

## 同步与状态

FastAPI生命周期启动独立enterprise_sync_loop，扫描已确认上传、尚未导入的第二代数据集。
按ID游标循环处理，避免某个长时间校验中的任务阻塞其他数据集。
同步器自行读取模型服务校验状态，不依赖工作台页面轮询。

- 校验未完成：显示校验/导入中。
- 校验失败或取消：展示失败状态，工作台可查看原因。
- 缺少标准企业产物：明确要求重传历史数据，不生成伪数据。
- 导入失败：事务回滚，记录错误码和60秒重试时间；页面支持手动重试。
- 导入成功：企业表与导入摘要原子提交，自动出现在数据集总览和检索中。

复用既有导入的SHA256、源契约、记录计数、快照内引用、幂等与并发锁校验。
后台任务在应用关闭时取消，数据库状态支持进程重启后继续扫描。
无需新增数据库迁移；同步错误和退避保存在数据集execution.enterpriseSync中。

## 接口及范围

- `modeling/enterprise-sources`：分页列出当前用户已确认上传的数据集和导入状态。
- `modeling/enterprise-overview`：单数据集记录数、标签0/1/未标注、模型预测统计与前8家企业预览。
- `modeling/list-enterprise-records`：复用既有企业检索与模型预测关联。
- `modeling/enterprise-company`：精确企业ID详情、每类前20条同快照关系/事件、最多100个模型已有预测。

所有上传数据接口通过会话校验并验证数据集归属；模型必须属于同用户、同数据集。
重复企业ID按数据集隔离；人物及关系进一步按快照隔离。
总览按已导入的完整企业表聚合，前8家预览不代表总体分布。
标签只展示0/1及未标注，业务含义来自当前目标定义，不统一称作健康/困境。

总览中的模型统计来自已登记模型及已保存预测：每模型计数、预测类别1数量、
平均主分类概率与平均不确定性。无预测时均值为空，不能解释为低风险。
模型推理仍受保存图ID范围约束，切换数据集不能扩展旧模型的预测范围。

## 验证

独立PostgreSQL验证校验后自动导入、幂等、导入失败原子回滚与退避、
多用户隔离、同用户多数据集相同企业ID隔离、标签和预测统计、
检索、同快照关联详情与跨数据集模型拒绝。

前端验证构建、类型和lint，并在实际本地页面检查总览/检索的数据源选择器。
内网Qwen不参与这条链路。
