# 分支合并后的迁移编号

本次同步的两个分支分别将 `V0010` 用于数据准备和对话耗时。合并后迁移链统一为：

- `V0009`：助手会话。
- `V0010`：数据准备案例，保留本地已运行版本。
- `V0011`：转换方案与试运行，保留本地已运行版本。
- `V0012`：对话结束时间及耗时，从远端分支的冲突编号移至新编号。

`V0012` 检查列是否已存在，兼容远端已经创建耗时字段的数据库；不会修改已有字段或历史耗时值。新安装及已经完成本地 `V0011` 的环境直接执行正常 `alembic upgrade head`。

## 运行过原远端 V0010 的环境

仅凭 `alembic_version=V0010` 无法判断是哪条分支，升级前须检查实际结构。若确认 `assistant_turns` 已含 `finished_at` / `duration_ms`，且 `data_preparations` 不存在，则这是原远端分支：备份并确认后，将迁移标记恢复至共同的 `V0009`，再正常升级：

```sh
uv run alembic stamp V0009
uv run alembic upgrade head
```

此操作不删除业务表，后续 `V0010`/`V0011` 补齐准备链，`V0012` 保留已有耗时列。不得对已存在 `data_preparations` 的环境盲目执行该步骤。若结构与上述两种情况均不符，先核对迁移记录和表结构，再处理版本标记。
