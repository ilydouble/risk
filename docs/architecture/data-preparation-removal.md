# 数据准备功能移除

数据准备功能已移除，包括脚本工作区、历史案例编辑、字段建议、转换试运行和数据包交付。
前端不再提供 `/data-prep` 页面，后端不再注册 `/api/v1/data-prep` 接口。
智能助手不再接收浏览器案例快照，也不提供准备案例查询或转换工具。

模型工作台仍接收符合适配器契约的标准 ZIP；请在本地准备训练文件，再上传校验、训练和评估。
智能体模型配置及连接测试保留，接口移至 `/api/v1/assistant/model-defaults` 和 `/test-model`。
已有浏览器模型配置继续使用原存储键，以保留用户已保存的地址和模型名。

## 历史数据兼容

本次不删除数据库中的准备案例、转换结果或已导入数据集，也不改写 V0010、V0011、V0013 迁移。
`risk_api/modules/data_prep/` 仅保留历史 ORM 与确定性转换/溯源读取所需代码；没有 HTTP 或助手执行入口。
已导入企业仍可按冻结规则核验原始行，界面不再链接到已移除页面。
准备案例不再列入助手资产目录，现有训练数据集仍按账号隔离查询。

Compose 已移除 preparation-runtime、preparation-runner、preparation-worker 及相关环境配置。
已有部署更新时可使用 `docker compose up -d --remove-orphans` 清理旧服务容器。
