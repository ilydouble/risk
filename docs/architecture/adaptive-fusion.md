# UK缺失稳健融合

## 动机与范围

原模型使用一个全局系数混合节点/图表示。UK研究v2的超图覆盖与标签关联跨年份反转，
图表示幅值也随覆盖增加，导致测试AUC显著低于纯财务基线。
原因和原始指标见[训练诊断](uk-training-diagnosis.md)。

本次实现仅将UK研究v2新配置默认设为adaptive；旧UK、SMEsD和ACRA默认保持legacy。
图连接来自准备数据，不在反向传播中增删；编码、类型权重、门控和分类参数参与训练。

## 模型

- 主预测：`node_logits + gate * 0.5 * tanh(graph_correction)`。
  财务预测保持完整，图对每类logit的修正绝对值不超过0.5。
- 门控逐观察计算，输入为节点/图归一化表示、数值字段可用率、图可用性、有效类型比例和对数关联数。
  最后一层偏置初始化为-2，初始偏向财务；这不是推理时查看真实标签后调权。
- 无图观察门控严格为0，图证据严格为0；正式预测等于节点分类，DST辅助输出回到节点证据。
- 超图各类型仍使用原归一化拉普拉斯运算，跨类型改为按观察有效类型的加权平均。
  节点和图表示各经LayerNorm，减少覆盖数量与幅值的直接耦合。
- 节点投影宽度64、输出32；禁用固定随机企业身份输入。
- 从训练拟合的mean/scale恢复`*_missing`标志，缺失数值使用训练填充值；
  对标准化输入截断至[-10,10]。缺失保留为缺失，不制造财务记录或关系。

## 训练与选择

- 训练期对已声明数值/缺失标志配对的字段增加10%随机缺失；同时更新缺失标志和填充值。
- 训练期以20%概率屏蔽超边类型、50%概率按观察屏蔽图修正；推理期关闭扰动。
- 原EvidentialRiskLoss之外增加0.5权重的节点分类CE，让财务分支能独立预测。
- AdamW lr=0.001、weight_decay=0.01；保持余弦退火、梯度裁剪和验证分类CE选检查点。
- 历史legacy优化器和选模方式不变；新增验证AUC及节点CE记录只用于诊断。

门控也可能学习到不稳定规律，不能保证自动识别所有分布漂移；
该版本用有界修正、独立节点监督与训练扰动约束其影响。数据历史可用性仍需继续核实。

## 配置与兼容

UK研究v2配置声明增加可选项`fusion`，新配置显式冻结adaptive或legacy。
既有配置没有fusion时训练保留legacy；旧检查点architecture不变，继续原样重载。
新architecture为`riskgnn-plus-adaptive-v1`，容器格式仍为`riskgnn-plus-model-v1`。
算法身份、配置及fusionProfile随产物保存，不把旧模型静默解释成新结构。
HTTP DTO未改变，无需重导OpenAPI或生成前端DTO。

更新riskgnn与riskgnn-worker镜像后，刷新工作台配置并创建UK新实验即可使用adaptive。
已有实验配置保持原语义；对照实验可明确选择legacy。
