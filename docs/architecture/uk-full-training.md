# 英国全量训练

模型工作台的英国适配器支持 `target_count` 6–300,000；请求数量超过可用企业时使用全部可用企业。现有英国数据共 233,251 家，输入 `233251` 即覆盖全量，保留原训练、验证、测试划分。其他适配器的数据规模限制不变。

训练轮数支持 1–250，默认仍为 2 轮、2,000 家，适合流程检查。界面参数范围来自模型服务配置声明，不在前端另写上限。已完成实验的配置快照不变；参数声明更新后需刷新配置再创建实验。

英国图的运行边界为 300,000 节点、1,000,000 条超边成员关联；全量数据的 233,251 节点、789,487 条成员关联在范围内。普通边与超边保留在各自快照内，不跨训练、验证、测试图传播。

## 嵌入与训练

工作台企业嵌入为固定种子生成的 32 维随机向量，没有加载预训练嵌入。它是固定输入，不属于优化器参数。企业属性、关系和超边参与前向计算；投影层、异构图网络、超图网络、分类头与证据分支通过损失反向传播更新。`PortablePlus` 使用共享参数在不同快照执行，并通过 `functional_call` 将梯度传回同一份参数。

当前按验证集分类损失选择检查点。历史研究基准按验证集 ROC-AUC 选择，初始化和图处理也不同，因此增加数据量或轮数不等于复现历史指标。测试集只用于独立重载后评估；不得用测试指标选择轮数。

全量训练使用 CPU，耗时依赖当前机器和运行环境；历史研究脚本的时间不作为工作台 SLA。

## 验证记录

2026-10-17，在本地 Docker Linux x86_64 模型环境中，用官方英国 ZIP 做临时全量烟测：233,251 家目标企业、412,348 条普通边、789,487 条超边成员关联，一轮训练后独立重载测试成功。校验、准备、训练与测试合计约 43 秒，进程峰值 RSS 约 3.2 GiB。这是可运行性验证，不是收敛或模型质量验收；未向用户账号创建实验或发布模型。
