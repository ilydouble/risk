# 比赛离线部署手册

比赛机为 Linux x86_64，已安装 Docker Engine、Compose 插件、NVIDIA 驱动和 Container Toolkit。本机 A100 运行 UK 财务预测模型 `uk-financial-0.6b-v1`。智能助手通过比赛方提供的内网地址调用 Qwen3.6-35B，两台服务之间需要网络可达。

| 顺序 | 操作位置 | 操作与完成标志 |
| --- | --- | --- |
| 1 | 联网打包机，仓库根目录 | [构建和导出镜像](01-images.md)。按同一个 Git 提交构建，取得 GPU Compose 所需的完整镜像归档。 |
| 2 | 同一打包机，仓库根目录 | [组装离线部署包](02-bundle.md)。带上镜像、完整底座与 LoRA、Compose、初始化脚本和本手册，生成 `risk-offline.tar` 及其 SHA-256 文件。 |
| 3 | 数据提供方或联网打包机 | [单独交付数据集](03-dataset.md)。已有发布 ZIP 可直接交付，新版财务观测用仓库预设打包。ZIP 与摘要交给操作浏览器的人。 |
| 4 | 比赛服务器和演示电脑 | [现场启动与验收](04-onsite.md)。导入镜像，配置内网模型，验证 A100 推理就绪，从浏览器上传数据并完成一次可回看的预测。 |

命令使用 Bash。第 1、2 步默认从同一个干净且已提交的代码版本执行，归档放在仓库已忽略的 `backup/distributions/<提交号>/`。打包机需能访问镜像仓库和构建依赖源。下载模型时还需 uv、GitHub CLI 及访问 GitHub 和 Hugging Face 的网络。

**交接时分两处放文件。** 将部署 TAR 和对应的 `.sha256` 交给比赛机管理员，将数据 ZIP 和对应的 `.sha256` 交给演示电脑操作员。现场账号、数据库密码及内网模型令牌由管理员在比赛机配置。数据库表和对象存储由启动流程初始化，用户在比赛账号下导入正式数据。

赛前可在一台干净的 Linux 主机按第 4 步演练。演练时关闭公网，保留浏览器到前端和对象存储、后端到对话模型的内网连接。验收终点是刷新会话后仍能看到已保存的企业预测卡片。
