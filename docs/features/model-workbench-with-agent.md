# 模型工作台与智能助手联动

## 1. 业务目标

用户在工作台完成数据上传、训练、独立测试和模型发布后，可在智能助手中选择模型和企业，
执行真实预测并解读结果。模型版本页面用于管理已发布版本，不再要求用户在该页填写企业 ID 进行预测。

工作台管理模型生命周期；智能助手负责发现资源、引导选择、调用预测及解释结果。
助手不会自行训练、发布、删除模型，也不会把普通问答当作实际模型预测。

## 2. 两种数据入口

| 入口 | 接收内容 | 主要用途 | 是否直接用于训练 |
| --- | --- | --- | --- |
| 模型工作台 → 数据集 | 带 risk_dataset_contract.json 的 ZIP | 按已接入适配器校验、分析并创建训练实验 | 是，须通过对应适配器校验 |

UK、SMEsD、ACRA 等已准备好的训练数据应通过仓库打包工具生成 ZIP，再上传至模型工作台。
训练包由适配器解释数据、划分和特征；工作台执行任务并管理状态、记录和产物。

## 3. 主流程

1. **准备训练包**：选择数据集预设、数据目录及版本，用打包工具生成契约和 ZIP。
2. **上传并校验**：在工作台上传，等待全量校验及企业展示产物生成；失败时按错误修正数据。
3. **创建实验**：选择已校验数据集，设置允许调整的参数；每次实验保存独立配置快照。
4. **训练与测试**：查看执行状态、日志、指标及实际使用的数据规模；完成独立加载测试。
5. **发布模型**：从通过测试的实验发布版本，保存模型包摘要及测试报告。
6. **选择预测对象**：进入智能助手，查询版本，再定位该版本所属数据集中的企业。
7. **执行与留档**：助手调用真实模型服务，返回预测及可用解释，保存企业预测和对话执行记录。

示例：从仓库根目录打包 UK 数据集：

```bash
./scripts/package-dataset \
  --preset uk-companies \
  --data-dir datasets/uk_dataset_v1 \
  --dataset-version v1-20261017
```

默认输出 `models/runs/datasets/uk-companies-v1-20261017.zip`，已有同名文件不会被覆盖。
上传完整 ZIP，不单独上传 `train.json`；原训练、验证和测试划分由 UK 适配器保留。

## 4. 智能助手中的操作

### 从对话开始

用户可输入：

> 列出我最近发布的模型版本，说明数据集和测试结果，帮我选择一家企业进行预测。

助手先查询当前账号的已发布模型，返回名称、发布时间、数据集、算法和测试指标。
用户明确要求“最新”时可选对应范围内最新版本；否则多个候选需先确认。
按企业名称检索出现多个结果时，也应先确认原始企业 ID，不猜测编号。

### 从模型版本页面开始

点击“查看”核对版本信息，然后点击“使用此版本前往助手”。
系统携带版本 ID 预填对话草稿，用户发送后才执行；跳转不会自动调用外部大模型或预测服务。
页面还提供“在助手中浏览模型”入口。
企业详情已有的模型与企业上下文入口继续保留。

### 助手使用的能力

| 工具 | 业务用途 |
| --- | --- |
| enterprise_risk_catalog | 查询最近发布版本，或精确读取指定版本 |
| enterprise_risk_companies | 按名称或 ID 查询该模型所属数据集的企业 |
| enterprise_risk_predict | 对指定企业执行预测、按支持情况获取解释并保存结果 |

所有工具使用登录账号绑定的权限，模型不能指定其他账号。
工具调用及结果保存在对话记录中；助手应引用实际返回结果，不根据标签或关系自行编造预测。

## 5. 预测范围与结果解释

- 只支持所选模型绑定图内的企业；数据集企业总量可能大于本次子集训练包含的企业数。
- 企业检索命中不保证能预测，最终由模型服务校验图内身份；不支持时明确说明。
- 目录中的示例企业仅为预览，不代表完整图节点列表。
- RiskGNN+ 可返回特征敏感性解释；普通 RiskGNN 可以仅返回预测，不生成虚构解释。
- 分数针对数据集定义的企业状态标签，未经校准时不能表述为未来授信违约概率。
- 特征敏感性不是 SHAP，也不是因果贡献；关系存在不等于已测得关系的风险贡献。
- 测试效果不足等质量警告必须保留，不能因为成功执行就宣称模型可靠。

预测结果按模型版本及企业保存；有解释的结果可更新已有记录，普通预测不覆盖已有解释。
对话历史保留当时的工具输出，企业页面显示持久化的预测记录，两者用途不同。

## 6. 模型版本管理

模型版本按发布时间倒序展示，可查看来源实验、模型包摘要、大小和独立测试报告，也可下载模型包。

删除前弹窗说明范围，用户确认后删除：

- 该发布版本记录。
- 该版本关联的企业预测记录。

保留来源实验、数据集、对象存储模型包及助手历史对话。
删除后不能再用该版本 ID 查询或发起预测；从原实验重新发布会得到新的版本 ID。
已完成的历史消息不会改成另一版本，也不会因删除而从对话中消失。
删除版本不等于清理模型文件，已签发且尚未过期的下载地址也不会因此立即失效。

## 7. 验收要点

- 同一账号可完成发布 → 查询版本 → 选择企业 → 真实预测 → 查看保存结果。
- 多版本和同名企业不被静默选择，图外企业不产生伪造结果。
- 其他账号不能访问、预测或删除该模型。
- 页面跳转只填写草稿；助手没有删除、训练和发布工具。
- 删除后关联预测消失，来源实验和数据仍保留，历史对话可追溯。
- 服务不可用时明确报错，不将工具失败解释为模型预测。
