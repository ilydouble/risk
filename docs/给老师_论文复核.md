## 一、Table 2 需要改叙述 ⚠️

### 1.1 表本身没问题

**Table 2 原文**（从 PDF 提取）：

```
Conflict Stratum      Range of Conflict C     Sample Count     Actual Default Rate
Stratum 1 (Low)       [0.000, 0.084]          164              70.12%
Stratum 2 (Medium)    [0.084, 0.266]          163              66.87%
Stratum 3 (High)      [0.266, 0.672]          164              57.32%
```

**逐项验算：**

| 验算 | 结果 |
|---|---|
| 三档加权违约率 | (164×70.12 + 163×66.87 + 164×57.32) / 491 = **64.77%** |
| 论文自报的测试集违约率 | **64.77%** |
| **是否吻合** | **完全吻合 → 三档是真实、完整的划分，表没写错** |
| 趋势 | 单调下降 **−12.80pp** |
| 显著性 | 每档 n≈164 → **t ≈ 2.4**（不是抽样噪声）|

**→ 数据是对的，问题在正文的叙述方向。**

### 1.2 我们在自有数据上复现，方向相反

**脚本**：`run_conflict_strata.py`（同样的按冲突等分三档）
**数据**：自有英国数据集，n=46,631，**违约率 3.42%**
**配置**：250 epoch / seed 42 / evidence 权重

```
Stratum   区间               n        违约率     mean(pred)   档内 AUC
1 (低)    [0.000, 0.003]   15,544     0.32%      0.0003       0.6350
2 (中)    [0.003, 0.017]   15,544     1.01%      0.0031       0.6330
3 (高)    [0.017, 0.873]   15,543     8.94%      0.0549       0.7906
```

**→ 违约率随冲突【上升】+8.63pp；最高档是低档的 28 倍。**

（按融合不确定性分层结果一致：0.31% → 1.04% → 8.92%）

### 1.3 两边对照

| | 基准违约率 | 低冲突档 | 高冲突档 | 方向 |
|---|---|---|---|---|
| **论文（SMEsD）** | **64.77%** | 70.12% | **57.32%** | ↓ 下降 |
| **我们（英国）** | **3.42%** | 0.32% | **8.94%** | ↑ 上升 |

**→ 方向完全相反，差异在基准违约率（相差 19 倍）。**

### 1.4 机制

**冲突 `C` 度量的是两个分支的**分歧程度**（模型有多不确定），不是风险高低。**

**这个不确定往哪边偏，取决于**哪个类是多数**：**

| 场景 | 高冲突时模型在考虑什么 | 违约率走向 |
|---|---|---|
| 违约是**少数类**（英国 3.4%）| "这批里可能有违约的" | **升高** ↑ |
| 违约是**多数类**（SMEsD 64.77%）| "这批里可能有不违约的" | **降低** ↓ |

**→ 「高冲突 = 传染警报」只在违约率不过半时成立。SMEsD 的 64.77% 是极端基准，所以反向。**

## 二、建议改法

**方案 A（最小改动，推荐）** —— 改叙述，不动数据：

- 正文 `flags credit contagion anomalies` 改为
  **`an ambiguity signal that routes borderline cases to human review`**
- Table 2 下方加一句：

> "Note: conflict measures inter-branch disagreement, not risk magnitude. Its association
> with default reverses when the base rate crosses 50%: on SMEsD (64.77% default) the
> highest-conflict stratum has the lowest rate, whereas on a separate portfolio with a
> 3.42% default rate the highest-conflict stratum has the highest rate (8.94% vs 0.32%)."

**方案 B（升级为贡献）** —— 把这条写成方法论提醒：
**不确定性指标的有效方向依赖于基准违约率；在类别极不平衡的信用基准上，
不确定性指标不能直接当作风险指标使用。**

**⭐ 建议 A 为主体 + 一句话的 B。**

## 三、另有一处小地方（不影响结论）

**⑴ Table 3 的 `94.09% (Pass)` 建议改措辞**

目标 ≥95%，实测低 0.91pp。统计上 n=491 时 95% 比例的标准误是 0.98pp，
**数字没问题**；但标 `(Pass)` 容易被读成「已达标」。

→ 建议改为 **`94.09% (within 1 SE of the 95% target)`**

## 四、本次复核的局限（自查）

1. **英国复现只有 1 个 seed** —— 但分层是测试集内的确定性划分，与训练随机性关系较小。
2. **只有两个数据集** —— 若能在第三个中等违约率（如 20%）的数据上验证方向介于两者之间，
   就是决定性的检验。**目前未做。**
3. **未验证「高冲突组预测均值趋近 0.5」这个具体机制** ——
   英国高冲突档 `mean(pred)=0.0549`，远低于 0.5，所以不是简单的"拉向 0.5"。
