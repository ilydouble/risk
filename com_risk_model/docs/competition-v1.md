# 赛题十八第一版模型范围

已读取：两份赛题 Word 原文、决赛 SRS、申报书 Markdown，以及数据集调研；目录中的图片/白皮书等为辅助材料，未逐一解析。未发现附件1字段表或格兰德原始训练数据。

赛题原文强调：海外企业信用评估与决策、量化成效、稳定框架、数据安全与场景推广；创新/实效/技术安全/推广的 25/30/20/25 为参考口径而非最终规则。

SRS 将信用评分设为确定性模型，将报告生成与授信规则分离。因此当前交付聚焦 M3；先用公开基准跑通完整实验和模型服务，不把前端 mock 的 AUC/SHAP 当实测。

| 要求 | 第一版落实 | 状态/差异 |
|---|---|---|
| 确定性评分 | 固定种子、保存权重、eval 推理 | 已实现 |
| 企业关系风险 | 多关系 attention + 节点/通道 gate | 已实现，非标准纯 GraphSAGE |
| 社区先验 | 行业组 Beta-Binomial + 折外编码 | 已实现，非 Louvain/国别 |
| 归纳推理 | 特征模型，无节点 ID embedding | 新节点测试通过；跨国效果待验证 |
| 无标签预训练 | 同域遮蔽属性重建 | 已实现消融；收益由结果判断 |
| 校准与排序指标 | 验证截距校准、AUC/PR/KS/Brier/Lift/Capture | 已实现 |
| 基线 | LR、HistGradientBoosting、自身风险分支 | 未引入 XGBoost/评分卡 |
| 可解释 | 单属性扰动敏感性、真实入边列表 | 非 SHAP、无因果宣称 |
| 数据隔离 | 快照分离、公司去重、训练拟合预处理 | 时间戳不足，不能认证 PIT |
| 版本与 API | 权重/schema/hash/seed、localhost API | 现有 FastAPI/Dishka 单体推理，模型开发工程独立 |
| 国别/时间外推 | 当前中国 SMEsD | 待真实赛题数据，不虚构结果 |
| Co-Correcting/弱标签 | 未实现 | 真实破产标签基准先行 |
| UI/报告/决策 | 保留既有前端 | 本次不冒充完整系统交付 |

原始参赛材料不作修改。实现与研究结果保存在 com_risk_model/，HTTP 接口位于 backend/。
