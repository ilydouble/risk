# 海外企业信用评估与授信决策系统

## 1. 项目描述
面向跨境金融 / 贸易授信场景的**内部风控工作台**。目标用户是信贷审批人员、风控分析师与业务经理。
核心价值：把「查企业 → 看画像 → 查关联图谱 → 看评分依据 → 出报告 → 给授信决策 → 验证模型 → 批量评估」串成一条完整链路，
让授信决策有据可依、可解释、可复现。界面为中文，采用浅色专业风：瓷白底、宝蓝（青花瓷）主色、墨蓝字、金色点缀，整体明亮清晰。

### 设计规范：状态点与状态标签
全站状态色（连接状态 / 系统服务 / 风险等级 / 存续与上线状态）统一采用「蓝 · 赭金 · 红」三色语义：
`低/正常/已连接/已上线/存续 → 钴蓝`、`中/降级/演示/需关注 → 赭金`、`高/中断/告警 → 红`。
- 唯一状态点：`src/components/base/StatusDot.tsx`（只有圆点）。
- 唯一「状态点 + 状态文字」标签：`src/components/base/StatusPill.tsx`；风险等级徽章 `RiskBadge` 亦基于它封装。
标签样式（软底、描边、圆角、字号、点距）统一由 `StatusPill` 负责，业务组件禁止各写各的。
色值均来自 CSS 变量 `--risk-low/medium/high`，禁止硬编码状态色。
- 唯一悬浮提示：`src/components/base/Tooltip.tsx`（Portal + fixed 定位，不被 overflow-hidden 裁切）；语义文案真源为 `src/constants/status.ts` 的 `RISK_HINT`。
  `StatusPill` 默认悬浮显示对应颜色语义（蓝=低/正常/已连接、金=中/降级/演示、红=高/中断/告警），`StatusDot` 可按需 `tooltip` 开启。

## 2. 页面结构
左侧导航分两组：**工作台**（总览看板 / 企业检索 / 企业画像）、**模型与评估**（模型档案 / 批量评估）。
「企业画像」为父级入口，其 4 个下钻页（图谱关系 / 评分详情 / 报告页 / 决策单）以页面顶部**横向 Tab**切换，不再平铺在侧边栏。
「模型档案」同为父级入口，「评估看板」作为其下钻子页，以顶部**横向 Tab**（档案概览 / 评估看板）切换：档案概览讲清「模型是什么」，评估看板回答「模型准不准」。
- `/` - 总览看板（覆盖企业数、风险分布、今日评估量、系统状态、趋势图）
- `/search` - 企业检索（中英文名称 / 注册号模糊搜索，结果列表）
- `/company/:id` - 企业画像（画像概览 Tab：工商信息卡 + 变更时间线 + 风险标签 + 5C 雷达图）
- `/graph` - 图谱关系（企业画像子 Tab：力导向图，2-3 跳，风险染色，下钻，风险传导路径高亮）
- `/score/:id` - 评分详情（企业画像子 Tab：信用分 / 风险分位 / 违约概率 + SHAP 瀑布图 + 社区风险对比）
- `/report/:id` - 报告页（企业画像子 Tab：流式生成正文，句末引用角标，悬浮证据卡）
- `/decision/:id` - 决策单（企业画像子 Tab：授信额度、账期、结算方式、缓释建议、命中规则）
- `/model-card` - 模型档案（模型中心父级 Tab：模型身份 / 架构链路 / 训练数据 / 全局特征重要度 / 版本演进 / 漂移监控 / 治理合规）
- `/model` - 评估看板（模型档案子 Tab：AUC/KS/Lift/Brier、校准曲线、消融实验、跨国外推衰减，均带「复现」）
- `/batch` - 批量评估（上传名单 → 批量评分排序 → 导出）

全局能力：演示模式开关（一键初始化 + 预置案例）、顶部全局搜索、左侧分组导航、企业画像横向子页 Tab、报告生成进度条。

## 7. 国际化（i18n）
全站支持中文 / 英文双语，运行时可切换（顶栏语言切换器），选择记忆于 localStorage（key `credit-lang`），默认中文。
- 基础设施：`src/i18n/index.ts`（i18next + react-i18next）；词条按语言分文件存放于 `src/i18n/local/{zh,en}/[namespace].ts`，由 `src/i18n/local/index.ts` 聚合，每个文件顶层 key 作为命名空间，需全局唯一。
- 命名空间约定：`common`（品牌 / 导航 / 顶栏 / 页签 / 面包屑 / 状态 / 风险语义）、`overview`、`search`… 每个页面一个命名空间。
- 组件取词统一用 `useTranslation()`；双语数据字段（企业中文名 / 英文名、预置案例等）用 `src/hooks/useLang.ts` 的 `pick()` 按语言取值，案例类文案（如预置案例标题）以 id 为桥接落到对应页面词条。
- 状态语义文案 `RISK_HINT`、风险等级标签改为 i18n key，由消费组件翻译，保证「蓝 · 赭金 · 红」口径中英一致。
- 数据正文双语策略：企业画像的档案正文（综合结论、工商信息、变更时间线、风险标签、5C 说明、关联方）以**可选英文副本字段**（如 `summaryEn` / `titleEn` / `labelEn` / `noteEn` / `factsEn`）保留英文，中文原字段不变；企业数据另加 `countryEn / industryEn / tagsEn` 供画像头部与检索结果卡展示，并补 `regionEn / sectorEn` 供检索页分组头与筛选下拉按语言取值（组件统一走 `useLang().pick()`；分组名随 `labelEn` 附带，下钻提示同步取本地化组名）。
- **生成器双语策略（下钻四页）**：图谱 / 评分 / 报告 / 决策的核心内容由 `src/pages/{graph,score,report,decision}/lib/*.ts` 运行时拼装（节点、SHAP 因子、报告正文、决策规则等）。这些构建函数新增可选 `lang: "zh" | "en"` 参数（默认 `"zh"`，故批量评估等未国际化调用方零影响），内部用本地双语字典按语言产出文案；组件把当前语言传入 `useMemo` 依赖即可整体切换。共享元数据（`nodeTypeMeta / edgeTypeMeta / evidenceTypeMeta / GRADE_BANDS / decisionOutcomeMeta / ruleSeverityMeta`）加 `*En` 字段，由组件按语言选取。
- **模型档案 / 评估看板双语**：看板指标口径（`fullLabel / hint / desc`）、消融特征组、外推国别与判定、复现步骤均在 `src/pages/model/lib/eval.ts` 的 `buildEvalDashboard(version, lang)` / `buildReproduceRun(dashboard, key, lang)` 内按语言产出，分组名由 `cohortLabel(lang)` 提供；档案正文（模型身份 / 架构与推理链路 / 训练数据 / 版本演进 / 漂移监控 / 治理四组）以可选英文字段（`*En`）保留英文，中文原字段不变，组件用 `useLang().pick()` 取值。
- **批量评估双语**：批量结果行（企业名 / 国别 / 行业 / 信用等级 / 风险等级 / 建议结论 / 问题备注）与流水线步骤、状态标签、CSV 表头由 `src/pages/batch/lib/batch.ts` 的 `buildBatchRows / buildBatchSummary / buildBatchRun / buildResultCsv` 按可选 `lang` 参数产出（`getStatusMeta(lang)` / `statusLabel(status, lang)` 替代原常量）；行内 `countryEn / industryEn`、风险分布 `labelEn`、名单 `fileNameEn` 作为可选英文副本；页面另提供英文示例名单 `sampleRosterCsvEn`（mock）与引号内逗号的首列解析支持。
- 状态：`common` + `overview` + `search` + `company` + `graph` + `score` + `report` + `decision` + `model` + `batch` **全部完成**（工作台整组 + 模型中心整组），企业检索的结果卡 / 分组头 / 筛选下拉亦已双语化，全站中英双语彻底闭环。
