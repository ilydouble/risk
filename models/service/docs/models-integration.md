# models 主线集成验收

日期：2026-10-07。研究基线为 dev `4cae79a`，隔离 Compose 项目 `risk-models-integration`。

## 边界与兼容

- 统一服务位于 `models/service/`，业务 API 仅通过内部 HTTP 调用。
- `models/riskgnn/requirements.txt` 与 dev 一致；原脚本参数、Python/CUDA 环境保留。
- 研究源码只增加包导入兼容，并抽取原采样/优化步骤供服务复用。
- 与最新 dev 原研究 CLI 在相同 90 节点合成数据上各训练一轮，8 组预测数组逐元素一致。
- 原基线、RiskGNN、RiskGNN+ 源码均进入镜像，本地数据/模型/虚拟环境排除。
- 当前开放 `riskgnn-node-edge` 和 `riskgnn-node-only`；其他模型明确不可训练。
- Bundle v1 恢复校验、质量/信号/PSI/泄漏分析，不迁入旧 Worker，也不开放不兼容训练。
- 旧实际模型包由迁移前后两套代码加载，8 家企业预测最大差异为 0。
- 模型代码摘要在宿主机与容器相同；旧数据库记录、对象及本地产物保持原位。
