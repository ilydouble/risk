## 执行与隔离

- 真实 PostgreSQL 临时 schema 验证提交幂等、事务回滚、过期接管、旧执行者隔离、
  最多三次执行、取消和事件游标恢复。
- 模拟产物上传失败：第二次 Attempt 复用已测试的模型，没有新增训练 epoch。
- 实际训练时 SIGKILL Worker：60 秒租约到期后由第二个 Attempt 接管并完成。
- 实际训练中取消：计算进程终止，任务进入 cancelled；修正了事件先于心跳感知取消的竞态。
- 停止模型 HTTP 服务：auth/me、企业读取仍为 200，模型预测返回统一 503；随后恢复服务。
- 第二个注册用户不能读取、查询事件、下载或预测另一个用户的资源（404）。
- 模型存储身份可读 risk-modeling，对 risk-documents 的 HEAD 请求被拒绝（403）。
- 后端容器无 torch、riskgnn、com_risk_runtime；服务没有模型宿主机端口。
