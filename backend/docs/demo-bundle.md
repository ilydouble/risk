# SMEsD 最小共享演示包

本包用于本项目的共享调试与展示，包含474家匿名测试企业、关联个人节点、观测关系、司法事件编码，以及已有训练所选出的 no_hyper-seed42 模型。完整企业训练集、验证集、原始 pickle、新加坡数据和竞赛数据不包含在包内。

## 来源与处理

- 来源：ComRisk 官方仓库 https://github.com/shaopengw/ComRisk ，固定提交 `a80524b3b67436cd2f74755f6ffa08a554ff2d02` 中的 SMEsD。
- 数据获取与原始文件校验：`backend/scripts/fetch_smesd.py`。
- 转换：`backend/src/risk_api/modules/benchmark/engine/smesd.py`。按 train、valid、test 的先后归属消除跨集重复；原测试491企业变为474企业；资本 log1p、边权处理、端点过滤等规则见后端 README。
- 模型：本项目的 ComRisk-inspired 独立实现，在去重后的公开训练集上训练，验证集用于选择、校准与阈值拟合。测试标签用于评估，不用于参数更新。
- `summary.json` 保留18次实验汇总；其中其他17个模型目录并未随包提供，需重新训练才能获得。路径已改为仓库相对路径。
- 文件清单与 SHA-256：同目录 `demo-bundle-manifest.json`。最小包直接使用现有服务默认路径，不需要复制或解压步骤。

## 使用与验证

按根 README 安装依赖后，启动后端和前端即可。后端启动从演示权重计算企业预测，不依赖上游网络。

可运行 `backend/tests/test_demo_bundle.py` 检查文件校验和，以及只复制清单内文件到独立目录后加载模型并推理。接口信封另由 `backend/tests/test_benchmark_api.py` 检查。

本包不含虚拟环境；缺少 PyTorch 等依赖时仍需先安装。通过数据获取和 benchmark 脚本重训会更新本地权重与汇总；若要发布新版本，应同步更新清单校验和和结果说明。

## 范围与许可说明

此包展示公开基准上的破产风险分类，不是未来固定窗口违约概率，不证明东南亚企业泛化效果。特征遮蔽解释不是 SHAP，线性演示信用分不是业务评分卡。

公开可下载与明确的再分发许可并不等同。本次未确认上游提供明确再分发许可；保留来源不构成对上游数据重新授权，也不将仓库所有者的上传授权表述为上游许可。第三方数据与依赖的权利和适用条款仍归各自权利方。
